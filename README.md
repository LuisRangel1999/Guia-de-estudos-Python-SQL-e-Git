## 📌 Conteúdo do Guia

Este guia de estudos está estruturado em três grandes pilares, abordando desde conceitos fundamentais até tópicos avançados com exemplos práticos:

### 🐍 1. Python (Lógica de Programação e Desenvolvimento)
Python é uma das linguagens mais populares e versáteis do mundo, sendo ideal para desenvolvimento web, ciência de dados, inteligência artificial e automação.
*   **Fundamentos e Variáveis:** Tipos de dados primitivos (`int`, `float`, `str`, `bool` e `complex`).
*   **Controle de Fluxo:** Estruturas condicionais (`if`, `elif`, `else`) e tomada de decisões.
*   **Laços de Repetição:** Repetições dinâmicas e condicionais usando `for` e `while`.
*   **Coleções de Dados:** Manipulação avançada de listas (dinâmicas e mutáveis), tuplas (imutáveis) e dicionários (chave-valor).
*   **Organização e Modularização:** Declaração de funções (`def`), uso de parâmetros padrões/opcionais e controle de escopo (local vs. global).
*   **Módulos e Bibliotecas:** Organização do código em múltiplos arquivos e uso do gerenciador de pacotes `pip` para instalar bibliotecas de terceiros.
*   **Programação Orientada a Objetos (POO):** Classes, objetos, métodos construtores (`__init__`), herança, herança múltipla e polimorfismo.
*   **Manipulação de Arquivos:** Leitura e escrita em arquivos externos (como arquivos `.txt`) usando manipuladores e blocos `try-except` para tratamento de exceções.

### 🗄️ 2. SQL (Bancos de Dados Relacionais)
Linguagem de consulta estruturada universal para interagir com Sistemas de Gerenciamento de Banco de Dados (SGBDs) como **MySQL** e **PostgreSQL**.
*   **Conceito Relacional:** Estrutura de bancos de dados compostos por tabelas (entidades), colunas (campos) e linhas (registros).
*   **DDL (Data Definition Language):** Criação (`CREATE`), alteração (`ALTER`), exclusão (`DROP`) e limpeza (`TRUNCATE`) de estruturas de bancos de dados.
*   **DML (Data Manipulation Language) & DQL:**
    *   Consultas essenciais com `SELECT`, filtros refinados (`WHERE`, `AND`, `OR`, `NOT`, `IN`, `BETWEEN`, `LIKE`).
    *   Ordenação e limitação de resultados (`ORDER BY`, `LIMIT`).
    *   Inserção (`INSERT`), atualização (`UPDATE`) e deleção (`DELETE`) de registros com segurança.
*   **Funções de Agregação & Agrupamentos:** Cálculos matemáticos de grupo (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) e sumarizações de dados com `GROUP BY` e filtragem após agrupamento (`HAVING`).
*   **Relacionamentos (JOINs):** Junção de tabelas através de Chaves Primárias (Primary Key) e Chaves Estrangeiras (Foreign Key) usando `INNER JOIN` (ou aliases para simplificação de código).
*   **Tópicos Avançados:** Criação de Subqueries (consultas aninhadas dinâmicas) e Views (visualizações persistentes para consultas frequentes).

### 🌿 3. Git & GitHub (Controle de Versão e Colaboração)
Git é a ferramenta indispensável de versionamento de código aberto que atua como uma verdadeira máquina do tempo para o desenvolvimento seguro e colaborativo de projetos.
*   **Áreas de Trabalho:** Entendimento do fluxo entre o diretório de trabalho local (*Working Directory*), área temporária de preparação (*Index/Stage*) e o repositório local (*HEAD*).
*   **Comandos Essenciais:** Inicialização com `git init`, indexação com `git add`, gravação permanente com `git commit -m` e navegação no histórico com `git log` e `git status`.
*   **Ramificações (Branching):** Desenvolvimento isolado de novas funcionalidades em branches paralelas (ex: `feature`, `dev`, `experimental`) sem afetar o ramo principal (`main`/`master`).
*   **Trabalho Remoto & GitHub:** Sincronização e envio de alterações (`git push`), download e mesclagem de atualizações (`git pull`, `git fetch`), além do clone de repositórios externos (`git clone`).
*   **Mesclagem (Merging):** Integração de alterações paralelas com `git merge` e `git rebase` (histórico linear).
*   **Trabalho em Equipe e Boas Práticas:** Resolução manual de conflitos de código, uso de Pull Requests para revisão e aprovação antes do merge, marcação de marcos com `git tag` e prevenção de versionamento acidental com o arquivo `.gitignore`.
